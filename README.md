# Fare Tracker (Android)

1. Create a free GitHub account and a new empty repository.
2. Upload ALL files from this folder, keeping the structure
   (including the hidden `.github/workflows/build.yml`).
3. Open the repo's Actions tab. The "Build APK" run starts automatically
   (first build takes about 15-30 minutes).
4. When it finishes, open the run and download the `faretracker-apk` artifact (a zip).
   Unzip it and copy the .apk to your phone.
5. On the phone, allow "Install unknown apps" for your file manager/browser, then install.
6. Open the app, enter your itinerary and Amadeus API key/secret, tap Save & Start.
   Allow notifications when asked, and exempt the app from battery optimization
   (Settings > Apps > Fare Tracker > Battery > Unrestricted).
